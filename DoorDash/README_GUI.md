
# DoorDash JavaFX GUI

## Added Features
- Full JavaFX GUI
- Role selection menu
- Interactive 100-cell board
- Dynamic monster tracking
- Dice rolling
- Powerup activation
- Visual cell differentiation
- Status tracking
- Winner detection

## Main Entry Point
Run:

game.gui.DoorDashApp

## Notes
- Requires JavaFX SDK.
- The GUI directly uses the existing game engine.
- MVC-style separation is maintained by keeping engine logic untouched.

## Suggested VM Arguments
--module-path "PATH_TO_FX/lib" --add-modules javafx.controls,javafx.fxml
